# RevenuePilot — AI-Powered Revenue Decision Intelligence

## Overview

RevenuePilot is a business intelligence project designed to help e-commerce businesses understand revenue performance, investigate changes, forecast future revenue, and analyze customer purchasing behavior.

## Business Questions

- Why did revenue increase or decrease?
- Which products, regions, and customer segments contributed to the change?
- What revenue can be forecast for the next four weeks?
- Which customer segments show declining repeat purchases?
- What should a business manager investigate first?

## Planned Technology Stack

- Python, Pandas, and NumPy
- PostgreSQL and SQL
- Power BI
- Statsmodels or Scikit-learn
- Git and GitHub

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
